# Project conventions

These instructions apply to any AI agent or contributor working in this repository.

## Git commits

- **Never add a `Co-Authored-By:` line to commit messages.** Do not put it at the
  end of the message, and do not put it anywhere else in the message either —
  omit the trailer entirely.
- **Never add AI/tool attribution** of any kind (e.g. "Generated with…",
  "🤖", "Co-Authored-By: Claude…") to commit messages.
- Use Conventional Commit style: `type: short summary` (`feat:`, `fix:`,
  `chore:`, `refactor:`, `test:`, `docs:`), followed by a concise body that
  explains the *what* and *why*.
